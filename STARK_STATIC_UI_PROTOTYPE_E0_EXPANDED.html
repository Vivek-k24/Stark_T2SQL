Defense-in-depth layers

These are separate responsibilities. A model prompt and semantic catalog cannot grant or deny privileges.

01 / CONTEXTMinimize schema

Hide irrelevant objects and semantic definitions from the model. Not authorization.

02 / VALIDATORReject unsafe SQL

One SELECT-family statement, permitted objects, vetted expressions, AST re-generation.

03 / DATABASEEnforce entitlements

Login separation, column-level grants, row-level security, read-only execution, timeouts.

04 / EVALUATIONChallenge every layer

Direct-SQL and model adversarial cases, canaries, regression history, layer attribution.
